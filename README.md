## 🚀 What I've Built in Production

- **CI/CD Pipelines** — GitHub Actions and GitLab CI pipelines for Django and Node.js applications deployed to AWS EKS and EC2. Reduced deployment time and eliminated manual deployment steps.
- **Kubernetes on AWS EKS** — Managed containerized workloads with rolling updates, horizontal pod autoscaling, health checks, and zero-downtime deployments.
- **Multi-cloud Infrastructure** — Provisioned and managed production environments across AWS (EC2, S3, RDS, EKS), DigitalOcean (Droplets, Spaces), and Hetzner Cloud using Terraform.
- **Observability Stack** — Set up Prometheus + Grafana dashboards and ELK Stack for centralized logging, metrics, and alerting across multiple production services.
- **Cost Optimization** — Reduced infrastructure costs through right-sizing EC2 instances, S3 lifecycle policies, and moving appropriate workloads to DigitalOcean and Hetzner.
